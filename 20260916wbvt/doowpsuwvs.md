# 门诊预交金退款不用跑，手机点一点就搞定！

**市一通知****
**
为了方便市民朋友们办理门诊预交金退款，南平市第一医院推出了线上便捷退款服务。此外，还有自动退款的同步更新，快来体验吧！

**一、线上退款**

初次登录，微信搜 “南平市第一医院” 公众号，按提示绑好就诊卡，搞定基础操作～ 
**0****1****找到退款入口**
公众号点 “走进医院”→选 “预交金退款”→点“去提现”，再挑要退款的就诊卡，超好找！

**0****2****选退款方式，秒提交**
两种方式任你选，看清楚对应情况哦：

①原路退（3 个月内微信 / 支付宝充值专享）：

点 “原路退”→“去退款”，填个通知电话，选要退的订单，提交！钱直接回原充值账户，超省心～

②转账退（3个月以上订单 / 现金 / 银行卡充值用）：

点 “转账退”→“去退款”，按提示填信息（退微信填实名 + 电话，退支付宝填实名 + 账号 + 电话），传身份证 / 户口簿照片，提交等审核（3-7 个工作日），过了会发短信提醒！

**二、自动退款**

从2025年9月26日起，用微信/支付宝缴预交金，看完病账户若有剩款，系统会在就诊结束的14个自然日后，自动把钱按原路径退回去，无需其他操作！

划重点：一定要用自己实名的微信 / 支付宝缴费！别人代付的话，钱会退给代付人，别搞错啦～

以后退预交金，手机上点几下就搞定，再也不用跑医院！快转发给家人朋友，一起享方便～

**三、线下退款**

请携带就诊卡、就诊人有效证件（身份证、户口簿、护照等均可）；代办人需同时出示代办人有效证件及上述材料，前往南平市第一医院门诊收费窗口办理退款手续。
