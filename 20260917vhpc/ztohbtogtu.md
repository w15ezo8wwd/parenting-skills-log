# 母乳喂养周 | 昆明市妇幼保健院开展“生育友好环境塑造 健康生活方式倡导——支持母乳喂养，呵护健康未来”系列宣传活动

> 更新时间：2026-09-17 (UTC+8)

**昆明市妇幼保健院**

为积极响应第34个“世界母乳喂养周”号召，深入贯彻国家关于构建生育友好环境、倡导健康生活方式的决策部署，昆明市妇幼保健院开展了以“生育友好环境塑造 健康生活方式倡导——支持母乳喂养，呵护健康未来”为主题的系列公益宣传活动。

**社区科普下沉**

7月31日，昆明市妇幼保健院党委组织孕产保健党支部专家团队赴西山区福海街道怡心桥社区开展主题宣传。活动现场，医护人员在人流密集处精心设置了咨询服务台，针对哺乳期常见问题提供“一对一”的个性化解答和专业建议，向来往居民发放图文并茂的宣传手册。

**/ 现场照片 /**

为了更生动、更有效地传播科学知识，医务人员创新运用多种专业教具进行现场演示：借助“新生儿胃容量小球模型”，直观展示了宝宝出生初期微小但足够需求的胃容量，科学解释了初乳的珍贵，有效缓解了许多新手爸妈对“奶不够”的担忧；同时，结合婴儿模型、乳房教具等，示范了正确的哺乳姿势、喂养频率以及母乳的保存方法等实用技巧，让看似复杂的喂养知识变得通俗易懂、可学可用。

**孕妇课堂赋能**

8月2日、8月6日昆明市妇幼保健院在呈贡院区、华山院区举办了主题为“母乳喂养：支持赋能，守护未来”的专题孕妇课堂活动。活动聚焦母乳喂养核心，内容专业实用。

**/ 华山院区·孕妇课堂 /**

**权威开讲**

孕妇课堂由经验丰富的产科护士长担任主讲，围绕母乳喂养的核心益处（营养、免疫、情感纽带等）进行科学阐述，强化妈妈们的喂养信心。

**/ 华山院区·孕妇课堂 /**

**技巧精解**

针对孕产妇最关心的开奶时机、正确含接姿势、哺乳技巧、乳汁分泌促进方法以及常见问题应对（如乳头皲裂、奶量不足）等进行了生动详尽的讲解与模拟示范。

**/ 呈贡院区·孕妇课堂 /**

**互动答疑**

设置现场问答环节，专家耐心解答了准妈妈们关于哺乳期饮食、职场背奶、家庭支持等个性化疑问，气氛热烈融洽。

**新媒体作品策划**

为积极响应第34个“世界母乳喂养周”号召，昆明市妇幼保健院同步策划制作了一系列母乳喂养科普作品。
