# 宝宝总歪头如何破？妇幼康复专家来解惑

> 更新时间：2026-09-17 (UTC+8)

小儿先天性肌性斜颈是幼儿常见的一种颈部先天性畸形，患有此病的宝宝头部长时间不自主地向一侧倾斜，俗称“歪脖”。由于此病比较常见，所以徐州市妇幼保健院康复科主任李晓辉将以一个真实的病例提醒各位家长注意，不要错过最好的治疗时机。

**// 真实病例 //**

王先生和爱人是安徽人，女儿月月从出生十多天开始，就总是歪着脑袋，后来歪头的现象越来越明显，几乎整个上半身都是歪的。

王先生只好带着月月到合肥某医院就诊，经过一段时间治疗，女儿的症状毫无改善。

“检查费就花了27000多元，最后医生说是脑瘫。”王先生无法接受。

一个偶然的机会，王先生打听到，徐州市妇幼保健院康复科李晓辉主任擅长用中医推拿按摩治疗小儿脑瘫、小儿肌性斜颈、臀丛神经损伤、马蹄足内翻等疾病，而且对患者有耐心，医德高尚，专业负责。王先生就带着3个月大的女儿来到徐州。

李主任为月月做了细致的检查，发现月月其实是先天性肌性斜颈，可以通过推拿按摩的方法进行矫正治疗。

经过治疗，月月恢复情况良好，同一般孩子没有什么两样。王先生说，女儿在幼儿园表现很好，学习成绩也不错。“幸亏遇到徐州市妇幼保健院康复科李晓辉主任，不然女儿被当成脑瘫儿治疗，可能就没法正常上学了。”王先生感慨。

// **先天肌性斜颈？** //

李主任介绍，先天肌性斜颈，是由于一侧胸锁乳突肌挛缩导致的颈部偏斜，头和颈不对称畸形。直接原因是胸锁乳突肌纤维化，随后发生挛缩。而这种先天性肌性斜颈，如果不进行治疗，不会自行治愈，如果在早期没有发现，在孩子2－3个月后肿块会逐渐缩小，6个月后完全消失。但是同时会出现颈部偏斜，头向患侧屈曲，颈部向患侧旋转受限等问题，就是俗称的“歪脖子”。

李晓辉主任表示，小儿先天性肌性斜颈是小儿矫型外科疾病中常见的先天性畸形之一。多发生于右侧，部分合并先天性髋关节脱位。如果患儿没有及时治疗，长时间后逐渐会出现面部变形，左右面部不对称，孩子10岁以后可能会出现头部继发性畸形等情况，影响孩子的容貌。

**// 如何早发现小儿斜颈呢？//**

李晓辉主任表示，先天性肌性斜颈的早期发现，父母的细心观察真的很重要。而对于小儿先天肌性斜颈，越早发现治疗效果越好。

李主任说，患有先天肌性斜颈的孩子，刚出生的时候无法发现，但在**出生后15天左右会在颈部一侧出现肿块，呈椭圆形或梭形，质地较硬，皮肤正常，没有触痛。****早期患儿还会有眼睛一大一小，一只眼睛睁一只眼睛闭，只往一侧睡觉，转头受限，脸部双侧不对称的情况。**

如果家长发现这些表现要重视，在孩子脖子部位摸一摸，看有没有肿块形成，如果发现有肿块应迅速到医院来检查和治疗。

**// 几个治疗的关键时期 //**

李晓辉说，如果家长能在孩子刚出生一个月或42天之内发现，此时肿块刚形成，可以通过推拿、按摩、理疗等方法矫正。推拿按摩的方法，一次或者两次就可以治愈，不会留下什么明显的后遗症。

如果发现的较晚，在42天到半岁后才发现，也可以通过推拿按摩的方法治疗，但是治疗的时间、难度和效果就要大打折扣。可能需要3个月或者半年的时间来做治疗。

如错过了最佳的非手术治疗时间，就只能通过手术的方式来解决，李主任认为最佳的手术治疗时间是一岁。

有部分孩子即使进行了手术，以后也可能出现头歪的情况，因为长时间的歪头已经造成身体两侧不对称，患儿也形成了习惯，而且手术后会留下疤痕，影响局部的美观。

李主任提醒，家长发现孩子异常，千万不能等“出月子”或者觉得孩子小等大一点后才带孩子来医院检查。

除了先天肌性斜颈，幼儿还可能出现习惯性斜颈，主要由于长期不良的姿势所导致。李主任表示，习惯性斜颈问题不严重，可以自行恢复。但如果时间持续比较长，患者可能要配合按摩等方法，进行矫正。
